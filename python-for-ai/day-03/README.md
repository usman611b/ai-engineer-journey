# 🔄 List vs Tuple

| List | Tuple |
|------|-------|
| Mutable | Immutable |
| Data can change | Data cannot change |
| Best for dynamic data | Best for fixed data |
| Supports adding/removing elements | Fixed after creation |

# 🧠 Engineering Concepts Learned

Today I learned to choose the correct data structure based on the problem instead of memorizing syntax.

### Use List When:
- Data changes frequently
- Items are added or removed
- User-generated data

Examples:
- Student List
- Shopping Cart
- Attendance
- Search History

### Use Tuple When:
- Data should remain fixed
- Constant values
- Read-only information

Examples:
- GPS Coordinates
- RGB Colors
- Months of the Year
- Order ID
- Company Departments

---

# 🚀 Key Takeaways

- Every data structure has a purpose.
- Choose the right tool for the right problem.
- Think like an engineer instead of memorizing syntax.
